# houransai-web
芳藍祭2027年度のwebサイト用のリポジトリです。(22日更新)

##ほしい機能
<br>・芳藍祭について
・<shikokou-u.ac.jp>への接続ページ
・LitLinkのような作用(各SNSや各部門のメアドへの連携)
・芳藍祭アンケート
・電子パンフレット(めくりなどのモーション付き)
・Adminログイン機能
　・GoogleFormの代替(GoogleFormよりも楽にしたい)
  ・タスク管理表
  ・運営委員の掲示板(おしらせ等)
　・各部門の備品予約(演技リハ→コードリールx2 17:00-19:00　　みたいな使い方)
  ・報告画面
