# houransai-web
芳藍祭2027年度のwebサイト用のリポジトリです。(22日更新)

##ほしい機能
<br>・芳藍祭について
<br>・<shikokou-u.ac.jp>への接続ページ
<br>・LitLinkのような作用(各SNSや各部門のメアドへの連携)
<br>・芳藍祭アンケート
<br>・電子パンフレット(めくりなどのモーション付き)
<br>・Adminログイン機能
　<br>・GoogleFormの代替(GoogleFormよりも楽にしたい)
 <br> ・タスク管理表
  <br>・運営委員の掲示板(おしらせ等)
　<br>・各部門の備品予約(演技リハ→コードリールx2 17:00-19:00　　みたいな使い方)
 <br> ・報告画面
